# CARPETA DE ACCESORIOS PARA PERSONAJES - PICO PARK

Colocá en esta carpeta las imágenes PNG definitivas de cada accesorio con fondo transparente.

Nombres de archivo reconocidos automáticamente:
- Corona:    "corona.png" (o "crown.png")
- Gorro:     "gorro.png" (o "gorra.png", "cap.png", "beanie.png")
- Anteojos:  "anteojos.png" (o "gafas.png", "lentes.png", "glasses.png")
- Moño:      "moño.png" (o "mono.png", "corbatin.png", "bow.png")
- Sombrero:  "sombrero.png" (o "hat.png", "tophat.png")

Dimensiones recomendadas:
- Aproximadamente 36x28 a 48x36 píxeles con estética pixel art y canal alfa (transparencia).

El juego detectará y utilizará automáticamente las imágenes de esta carpeta tanto en la pantalla de selección de personajes como en las partidas y en el menú principal. Si falta algún archivo, el sistema utilizará el diseño procedimental de respaldo de forma transparente.
